⛁ Respaldo y archivo histórico

La copia completa de tu base de datos se guarda en el servidor (se conservan las últimas 15) y también se genera una automática cada día. La descarga incluye productos, clientes, ventas, kardex, cajas, créditos y recetas (no incluye usuarios ni contraseñas). Para restaurar una copia contacta a soporte.

FechaTipoUsuarioArchivo

Mueve ventas, kardex, cajas cerradas, cambios, abonos y recetas antiguos a hojas de archivo para que el sistema trabaje más rápido. No se pierde nada: antes se hace una copia de seguridad y el histórico se puede consultar marcando «histórico archivado» en Ventas y en Kardex. Las ventas a crédito con saldo pendiente nunca se archivan.
